## Initial Setup

The CLI includes an interactive setup wizard that guides you through authentication and configuration:

```bash
# Run the setup wizard
pinner setup

# Skip specific steps if needed
pinner setup --skip-auth
pinner setup --skip-config
pinner setup --reset
```

```bash
# Check version

# Run diagnostics
```
