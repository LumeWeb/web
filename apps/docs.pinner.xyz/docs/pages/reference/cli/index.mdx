A minimal, developer-focused CLI tool for pinning content to IPFS via the Pinner.xyz service.

## Install

See [Getting Started with the CLI](/ipfs/cli/getting-started) to install the Pinner CLI.

## Authentication

Most commands require authentication. Run `pinner setup` for the interactive wizard, or set `PINNER_AUTH_TOKEN` in your environment.

### [Content](/reference/cli/content)

| Command | Description |
|---------|-------------|
| [`upload`](/reference/cli/content#upload) | Upload files or directories to IPFS via the Pinner.xyz service. Content is converted to CAR format before uploading. |
| [`download`](/reference/cli/content#download) | Download content from IPFS by CID and save it to the local filesystem. Supports CID paths (e.g., CID/path/to/file) to download a specific file from a directory. |
| [`cat`](/reference/cli/content#cat) | Stream the contents of an IPFS CID to stdout. Supports CID paths (e.g., CID/path/to/file) to cat a specific file from a directory. |
| [`ls`](/reference/cli/content#ls) | List the contents of a directory pinned on IPFS by CID. Shows file names, types, and sizes for each entry. Supports CID paths (e.g., CID/path/to/dir) to list nested directories. |

### [Pinning](/reference/cli/pinning)

| Command | Description |
|---------|-------------|
| [`pin`](/reference/cli/pinning#pin) | Shortcut for 'pinner pins add'. Pin existing IPFS content by CID. Multiple CIDs can be provided as arguments, read from a file using --file, or piped from stdin. |
| [`pins`](/reference/cli/pinning#pins) | Manage your pinned IPFS content with subcommands for adding, removing, listing, checking status, and updating pin metadata. |
| [`list`](/reference/cli/pinning#list) | Shortcut for 'pinner pins ls'. List your pinned content with optional filtering. |
| [`status`](/reference/cli/pinning#status) | Shortcut for 'pinner pins status'. Check whether a pin has completed. If the pin is not found, account operations are checked as a fallback. |
| [`unpin`](/reference/cli/pinning#unpin) | Shortcut for 'pinner pins rm'. Remove pins by CID or remove all pins. |
| [`metadata`](/reference/cli/pinning#metadata) | The 'metadata' command has been removed. Use 'pinner pins update' to update pin metadata instead |
